# klab-ai — Python for AI

Course repo for the KLab AI program. Notebooks are for exploration; `src/` holds
code that has stabilised.

## Install and run

```bash
# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

Smoke test:

```bash
python -c "import numpy, pandas, sklearn, matplotlib; print('all good')"
```

Open the Day 1 notebook:

```bash
jupyter notebook notebooks/day01_python_for_ai.ipynb
```

## Project layout

```
klab-ai-<name>/
├── README.md              # how to install and run your work
├── requirements.txt       # exact library versions
├── .env.example           # names of secrets, never the values
├── .gitignore
├── notebooks/             # exploration: EDA, experiments
│   └── day01_python_for_ai.ipynb
├── src/                   # code that has stabilised
├── data/
│   ├── raw/               # never edited by hand
│   └── processed/         # generated by your scripts
└── reports/               # findings, write-ups, figures
```

Why it matters: notebooks are laboratories; `src/` is the product. Move code
across as it stabilises.

## Secrets

Copy `.env.example` to `.env` and fill in real values locally. `.env` is
gitignored — never commit secrets or large data.
