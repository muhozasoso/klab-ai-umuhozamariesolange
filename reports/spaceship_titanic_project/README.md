# Spaceship Titanic Project

## Overview

In this project, I used machine learning to predict whether passengers aboard the Spaceship Titanic were transported to another dimension.

## Dataset

Source: Kaggle Spaceship Titanic Competition

- Training records: 8,693
- Test records: 4,277

## Experiments

1. Baseline Logistic Regression (0.7860)
2. Feature Engineering (0.7921)
3. Random Forest (0.8020)
4. Gradient Boosting (0.8085)
5. Tuned Gradient Boosting (0.8123)

## Final Results

- Best CV Score: 0.8123
- Best Kaggle Score: 0.80547
